# 作品目录

本机源码工作台的新作品与程序分开保存。默认直接放在系统“下载”目录下；新建时可以选其他父目录，设置页“文件与存储”可修改以后新建作品的默认位置。不会增加“FilmOS项目/工作区/版本”等外层。

固定结构只到 `所选位置/作品名-短ID/分类/文件`。项目自己的模板版本为1，不称作行业统一标准。

```text
作品名-短ID/
├── 项目.json
├── 剧本/
├── 设定/
├── 分镜/
├── 提示词/
├── 素材/
├── 生成/
├── 导出/
└── 历史/
```

类别内不再分子目录。正文使用章节ID，素材、画布等加简短类型前缀；版本写在文件名或清单中。项目改名不自动移动文件夹；短ID只用于避免同名覆盖，业务身份不依赖目录名称。

## 保存内容与唯一权威

现有业务数据库仍是唯一编辑权威。作品目录是每次保存自动写出的内容与资源文件，不是第二套可独立编辑的项目库；不能只复制此目录便声称在另一台机器恢复完整工作台。

| 分类 | 实际内容 |
| --- | --- |
| 剧本 | 当前章节原始HTML或Markdown及业务记录，原文不改写；易读显示由工作台提供 |
| 设定 | 项目、角色/素材定义与版本、声音绑定、工作流及候选资料 |
| 分镜 | 业务镜头、画布JSON与章节/素材关联 |
| 提示词 | 已保存且绑定目标的当前提示词及来源记录，不等于图片生成 |
| 素材 | 项目引用的本地Resource实际文件与校验索引；远端对象仅明确标注外部引用，不自动下载 |
| 生成 | 现有工作流步骤与已登记结果索引，实际媒体复用素材文件；不自动发起生成 |
| 导出 | 手动“导出内容包”生成的ZIP，不含数据库、账号或密钥，不是成片制作器 |
| 历史 | 已有修订和被替换的受管内容，保留原版；不自动清理历史 |

媒体通过既有Resource链同步；`resource:`引用解析为本地资源或外部引用。全局媒体库可保留既有对象，不搬走其他项目共享的素材。项目本地文件流式复制，复制时再次校验摘要。

`项目.json`含schemaVersion、projectId、名称、受管文件摘要与currentFiles。旧目标被解除关联或删除后，其历史文件保留但不在currentFiles中；不要把目录里保留的旧文件当成当前版本。`.filmos-owner`是内部归属标识，请勿修改。

## 故障与恢复

- 项目页可查看/展开完整保存路径、检查状态、打开文件夹和导出内容包。“上次检查已同步”是检查时状态，不冒充持续实时监控。
- 磁盘离线、路径被符号链接替换、受管文件手工变化时停止后续内容修改，不另造替代目录，不自动覆盖冲突。
- 原目录已移动而旧位置不存在时，可“重新定位原目录”。必须选中同一projectId且文件摘要一致的原作品目录，不移动/复制任何文件。旧位置仍存在则拒绝建立第二份活动关联。
- 保存先进入pending；数据库已保存而目录写入失败时返回失败并标记sync_failed。先回读业务版本，再点击“重试同步”，不要重复创建内容。文件写入有摘要日志和原子替换，支持恢复已落文件而清单未确认的中断。
- 同一创建requestId复用原项目和路径。初建中断的记录会保留；无法证明目录归属则拒绝接管，不清理用户父目录。
- 旧项目不自动关联或迁移目录。跨机器恢复、手工文件自动导入、云同步和存量迁移不在此版本范围内。

## 本机限制

仅desktop_local且实际后端绑定回环地址时启用。创建/选择/重定位/同步/导出由同源、带自定义头的本机请求触发，不能用公网API传任意服务器路径。选择授权绑定用户、真实目录身份且15分钟失效；源码、运行数据、凭据和其他项目内部拒绝作为父目录。

macOS系统选择器由访达承载；取消不创建作品。不为此功能打包App。公开账号部署保留原项目创建/登录行为，不开放服务器目录选择；其他系统尚无可信选择器时明确不可用。
