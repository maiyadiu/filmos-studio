# 第五阶段验收矩阵

> `PASSED_LOCAL` 只表示合成数据、临时副本和本地运行闭环通过；不等于远端发布、真实迁移、签名发行或生产批准。

| 验收面 | 当前状态 | 通过条件 | 证据位置 |
| --- | --- | --- | --- |
| Remote/Hybrid 本地接线 | NOT_RUN | 默认关闭；显式选择；Human confirmation；manifest/version/hash 守卫；本地回执 | Web tests、Browser |
| 网络与上传边界 | NOT_RUN | 未授权时 network/upload 均为 0；无隐式 User Data Sync 复用 | Remote tests |
| Agent Adapter | NOT_RUN | Codex/DeepSeek-compatible 共用工具合同；权限不扩大；无密钥持久化 | Agent tests |
| Agent Approval 拒绝 | NOT_RUN | Read/Preview/Human Apply 分离；Agent 无 Approval 能力 | MCP tests |
| Dreamina 顺序门禁 | NOT_RUN | 全量回归稳定通过，不能靠删除、跳过或隔离运行冒充 | Agent native suite |
| 合成迁移包 | NOT_RUN | manifest/hash/ID/reference/row/FK 校验；幂等与故障恢复 | Migration tests |
| 真实 PostgreSQL / 用户数据迁移 | NOT_AUTHORIZED | 需独立授权、备份、恢复计划与真实环境 | Migration receipt |
| 性能基线 | NOT_RUN | 固定环境/数据集；p50/p95/错误率/包体可重放；预算明确 | Beta performance report |
| 上游兼容演练 | NOT_RUN | Stable/Candidate 重新发现；静态/原生门与回滚 dry-run | Upstream report |
| unsigned macOS App | NOT_RUN | release bundle 可复现；Info.plist/可执行文件/结构/启动 smoke 可验 | Desktop tests |
| 签名、公证与发布包 | NOT_AUTHORIZED | 需 Apple 凭据与显式外部发布授权 | Release receipt |
| 恢复与回滚 | NOT_RUN | Flag 回退、服务/DB/会话恢复、来源不变、无部分事实 | Recovery tests |
| Beta 总门禁 | NOT_RUN | Native/Contract/MCP/Golden/Migration/Recovery/Performance/Browser 全部如实归档 | Beta report |
| 外部执行 | NOT_AUTHORIZED | Provider、上传、额度、远端发布、生产同步均为 0 | 回执 |
