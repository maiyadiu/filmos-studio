# CR-12-001｜Remote 显式接线

STATUS: `ACCEPTED_STAGE_5_LOCAL_WIRING_IN_PROGRESS`

## 原因

Track 12 已在 `web/src/film/sync/` 建立默认关闭的本地权威模式与离线发布 Preview。
真正接入页面、共享 Film Contract、Host API 和后端持久化会跨越 Project UI、Film Core 与 QA 的文件边界，
因此本轨不直接修改共享文件。

## 请求

1. Program Integrator 确认正式引用字段是否进入 `film-contracts/**`：Film UUIDv4、version、content hash、Host object kind 与 opaque ID。
2. Project UI Owner 在明确用户操作后调用 Preview；不得把 Film Remote 接入 `installRemoteUserDataAutoSync` 或 `ensureRemoteResourceReferences`。
3. Remote Owner 后续实现独立执行器时，只接受用户已确认且 hash 未漂移的 manifest；执行前重查对象归属、Film version/hash 和选中资产集合。
4. Assets Owner 仅为清单内 `LOCAL_ONLY` 资产生成审片代理；原件默认不上传，代理上传仍需单独显式授权。
5. QA Owner 增加 Feature Flag 关闭、manifest 漂移、权限拒绝、部分失败、重试与审计测试。

## 必须保持

- `film.remote_sync` 默认 `false`。
- Local / Remote 冲突一律阻断，不得 last-write-wins 或静默覆盖。
- 未选中、未发布的本地资产永不隐式上传。
- 远端结果先进入 Candidate，不能自动成为 Approved / Locked / Primary。
- Preview 不得执行网络请求；正式发布状态必须来自独立执行器与可核验回执。

## 建议测试

- 关闭 Feature Flag 时 UI 与 API 均不可进入执行路径。
- manifest hash 与当前对象 version/hash 不一致时拒绝。
- 选中集合之外的本地资源上传数必须为零。
- Host opaque ID 只透传，不据其格式推断 Film ID。
- 执行器部分失败可重试且不把 Preview 标成已发布。

## 回滚

保持 Flag 关闭，撤销未来接线；当前离线 Preview 模块不影响影策既有 User Data Sync。

## 第五阶段裁定

接受默认关闭的 Project UI/本地服务接线、Human confirmation、manifest/version/hash 守卫、本地会话和追加回执；执行状态不得超过 `PREPARED_LOCAL`。网络执行器、上传、远端持久化和生产发布不在当前授权内，Remote 返回仍只能进入 Candidate。
