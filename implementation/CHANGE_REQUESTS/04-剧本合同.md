# 04 剧本合同请求

Owner：`track-film-core`

状态：`PARTIALLY_ACCEPTED_STAGE_2`

裁定：第二阶段已实现 Human-only Script Lock、`ScriptDecision`、当前 version/hash 守卫，以及未锁定脚本禁止进入 DirectorUnit；Cue/Section 稳定映射与精确 Impact 传播继续保留为后续工作。依据：`D-0005`。

## 原因

共享 V0 已有基础 `ScriptVersion`，但尚无 ScriptDecision、对白稳定 Cue 映射、锁定批准绑定和脚本变化到下游依赖的精确范围。Web 首切片只产生建议，不能成为正式 Film Core 真值。

## 请求

由 Track 02 裁决并扩展共享合同：

- `ScriptDecision` 绑定 `script_version_id + content_hash`，区分 Human 与 Agent；只有 Human `approve_for_lock` 可进入正式锁定。
- Script Lock 写命令使用 `expected_version + expected content_hash`，记录 Approval/AuditEvent。
- 对白 Cue 和可选 Section 使用稳定 ID；ImpactEdge 可声明依赖的 Cue/Section 范围。
- 正式 STALE 由 Film Core 写入；Web 分析结果只能作为 preview/recommendation。
- 未审查、未锁定或哈希不一致的 ScriptVersion 不得作为 DirectorUnit/Shot/PromptDraft 的正式输入。

## 测试

- 并发版本/哈希冲突；Agent 批准拒绝；人审后显式锁定；Cue/Section 精确传播；未映射变化不批量误标；审计追加。

## 回滚

保持 V0 `ScriptVersion` 不变并继续关闭 `film.story_studio`；不迁移 Host ProjectUnit 正文。
