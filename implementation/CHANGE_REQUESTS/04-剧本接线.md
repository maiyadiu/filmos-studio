# 04 剧本面板接线请求

Owner：`track-project-ui`

## 原因

Track 04 已在 `web/src/film/story/` 提供纯领域模块和 `StoryStudioPort`，但 `web/src/pages/projects/detail/**` 属 Track 03，Story 轨不直接修改。

## 请求

在现有章节编辑器右侧增加可关闭的 Story 扩展槽；只有 `film.story_studio=true` 且端口可用时显示“版本 / 审查 / 差异 / 影响 / 锁定”。关闭或端口失败时保持当前章节编辑、导入、角色提取和画布流程不变。

面板不得直接改写正文；AI 结果只能创建 `ai_proposal` 版本。锁定命令必须显示内容哈希并要求用户显式确认。

## 测试

- Flag 默认关闭时 DOM 与现有章节流程不变。
- dirty 正文不得被版本加载覆盖。
- 未审查/未锁版本不出现下游推进操作。
- 端口失败显示隔离错误，不伪装为服务端已保存。

## 回滚

移除扩展槽接线或关闭 `film.story_studio`；不迁移、不修改现有 ProjectUnit 正文。
