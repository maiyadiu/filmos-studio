裁定：`D-0005`。本阶段落地 DirectorUnit、CoverageLink 和 ContinuityCheckResult；SceneTwin、Blocking、Camera 的完整持久化留到 Golden C。

## 请求

1. 在 Film Contracts 中正式定义 DirectorUnit、DirectorShotCoverage、SceneTwinVersion、BlockingVersion、CameraVersion 与 ContinuityCheckResult。
2. Coverage 必须允许 DirectorUnit/Shot 多对多，不得复用 Host Shot ID 作为 Film DirectorUnit 身份。
3. 所有正式写入校验 `expected_version` 与 `expected_content_hash`，身份由 Film Core 生成 UUIDv4。
4. Canvas/Three.js/Blender 只提交 projection 或 Candidate；Approved 只能由 Review/Approval 正式链产生。
5. SceneTwin 正式合同覆盖坐标系、固定建筑/道具、Portal、WalkableZone、Anchor、CameraZone、ApprovedViewFamily 与 RGB/Depth/Normal/ObjectID 血缘。

## 验收

- 多个 DirectorUnit 可覆盖同一 Shot，一个 DirectorUnit 可覆盖多个 Shot。
- 跨轴、视线、动作入出状态或道具接触状态不一致时返回结构化 blocker。
- 过期 version/hash 不产生正式写入。
- 3D/Canvas 返回中不存在自动 Approved 路径。
