# CR-11-001｜正式迁移合同与导入事务

状态：`ACCEPTED_STAGE_5_SYNTHETIC_IN_PROGRESS`

提出轨：`11-migration`

目标 Owner：`track-film-core`、`track-assets`、`track-qa`

## 请求

1. Film Core 提供正式 `MigrationPreview`、`ImportPlan`、`IdMapping`、`ImportReceipt` 与 `RollbackReceipt` 合同。
2. 正式 ID 必须由 Film Core 预分配 UUIDv4；导入携带目标 `expected_version`、来源 SHA-256、来源系统、版本与引用图。
3. 正式 apply 前必须绑定独立目标备份回执和恢复验证；事务失败不得留下部分正式事实。
4. 系统 A/B Adapter 只提交结构化 Candidate，经过引用完整性、语义覆盖、QC 和人工批准后才能正式导入。
5. 迁移不得自动删除来源、历史失败证据、回执或被引用资产。

## 验收

- Dry-run 与正式 apply 使用同一锁定 manifest hash。
- 重放同一 manifest 幂等，冲突返回结构化报告。
- 缺失 ID、版本、SHA-256、来源、引用或备份回执时拒绝 apply。
- 回滚恢复后逐实体、逐引用和逐哈希复核一致。

第五阶段裁定：只接受合成数据、临时副本、迁移包与恢复回滚演练；真实系统 A/B、用户数据库和 PostgreSQL 正式 apply 仍需独立授权。没有真实 PostgreSQL 环境时必须输出 `BLOCKED_REAL_PG`，不得以 SQLite 或 JSON 往返冒充。
