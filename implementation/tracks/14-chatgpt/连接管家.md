# ChatGPT 连接管家

STATUS: `READY_FOR_EXTERNAL_CONNECTION`

## 产品边界

- 首次仅需 Tunnel ID 和 Runtime Key；Tunnel ID 进入本地偏好设置，Runtime Key 只进入 macOS Keychain。
- Film Core、FilmOS MCP、Project Grant 和官方 Secure MCP Tunnel 由桌面端的同一 `ServiceSupervisor` 管理。
- Tunnel 连通不等于 ChatGPT 已连接；只有真实 Tunnel MCP 读请求才能进入 `CHATGPT_REACHED_FILMOS`。
- MCP 对 ChatGPT 公开 20 个只读工具、0 个写工具。Proposal 仍需 FilmOS 校验、Command Preview 和 Human Approval。
- 计费模式锁定为 `SUBSCRIPTION_ONLY`；Runtime Key 只用于 Tunnel 控制面，不允许 OpenAI 模型 API 调用。

## 单一真值源

- 进程与重连：`desktop/macos/Sources/FilmOSDesktopCore/ChatGPTConnectionManager.swift`
- 本地服务、Grant 和 Tunnel：`desktop/macos/Sources/FilmOSStudioDesktop/DesktopChatGPTRuntime.swift`
- 原生界面：`desktop/macos/Sources/FilmOSStudioDesktop/ChatGPTConnectionWindow.swift`
- 真实读请求观测：`services/filmos-chatgpt-app/src/server.ts`
- 机器验收：`acceptance/checks/desktop_chatgpt_connection.py`、`acceptance/checks/no_openai_model_api_billing.py`

## 可复现证据

- Swift 覆盖 Keychain-only 配置、Core/MCP 自动准备、Tunnel doctor、断线重连、进程退出、Grant 续期、状态机、Live Gate Challenge 与密钥脱敏。
- MCP 集成测试覆盖真实 MCP Session 的首次读请求观测，并拒绝没有短期 Transport Proof 的 localhost 伪造。
- Acceptance 生成独立 `no-openai-model-api-billing-receipt.json`，要求 `observed_model_api_calls=0`。

## 外部停止点

本地实现、构建和自动化验收通过后，仍需用户首次提供 Tunnel ID 与 Runtime Key，并在 ChatGPT 完成 Developer Mode/App 连接。在真实读回执前，状态必须停在 `WAITING_FOR_CHATGPT`，不得伪装外部 Gate 已通过。
