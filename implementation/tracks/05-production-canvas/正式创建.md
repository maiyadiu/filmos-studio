# Production Canvas 正式创建

`POST /api/projects/{projectId}/units/{unitId}/production-canvas`

请求：

```json
{
  "humanConfirmed": true,
  "confirmationId": "human-confirmation-uuid",
  "expectedRevision": 7,
  "expectedContentHash": "64 位小写 SourceText SHA-256"
}
```

成功数据：`canvas`、`link`、`disposition`、`projectRevision`、`observedContentHash`、`auditEventId`、`confirmationId`、`confirmedByUserId`、`confirmedAt`。

- Host 开关：`CANVAS_FILM_PRODUCTION_CANVAS_WRITE_ENABLED=true`；默认关闭。
- 400：缺少 Human 确认或请求字段无效。
- 403：Host 写开关关闭。
- 404：项目/Unit 不存在或当前用户不拥有。
- 409：Project revision、SourceText hash、归档状态或历史 production 关联冲突。
- 首次创建回执 `created`；同自然键重试回执 `reused` 和原 Audit ID，不再 bump revision。
