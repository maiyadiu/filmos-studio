# 第六阶段｜Release Candidate 本地收口与 Track 14

## 目标

在第五阶段 Beta 本地门禁通过的基础上，并行完成两条主线：

1. Release Candidate 本地收口：Web 拆包、统一恢复演练、上游 C 级迁移适配与 RC 总门禁。
2. Track 14 Day 1–5：FilmOS ChatGPT App、私有 Secure Bridge 边界、MCP Apps Widget 与 `.filmosproposal` 回传。

本阶段的最高自动状态为 `PASSED_LOCAL_RC`。ChatGPT 账户连接、Secure MCP Tunnel 控制面、真实用户数据库迁移、外部 Provider、Apple 签名/公证和生产发布必须有独立授权与外部回执，不能由本地测试替代。

## 官方能力裁定

- 当前官方插件形态使用 MCP Server；新 UI 优先使用 MCP Apps bridge，`window.openai` 仅作 ChatGPT 扩展和兼容层。
- Secure MCP Tunnel 是出站式私有连接，可用于 Developer Mode；它需要 Platform Tunnel 权限、runtime API key、ChatGPT Developer Mode 与实际 tunnel 关联。本阶段只实现本地 server/connector/config/doctor/fail-closed，不自动创建或运行外部 Tunnel。
- 发布插件需要稳定公共 HTTPS endpoint；本阶段不提交、不发布，也不把本地或 Tunnel 开发验证写成公开发布。
- 已发布 MCP metadata 使用审核快照；V1 工具名、URI 与 schema 必须向后兼容，变化后需 Refresh/Scan/新版本。

## Track 14 实施边界

- 主形态为 `interactive-decoupled`：标准 `search` / `fetch` 和 FilmOS 数据工具不挂 Widget；独立 render 工具挂版本化 UI resource。
- 所有 Pro/V1 读取工具必须 `readOnlyHint=true`、项目级 Grant、最小输出、无绝对路径/密钥/Cookie/数据库/原始 4K 媒体。
- Grant 默认单项目、短期、可撤销；项目文本按不可信内容处理，不能改变权限或工具集合。
- Pro 本地交付不暴露 write tools。`.filmosproposal` 必须校验 schema、签名、过期、project、base state/version、content hash、非法命令和幂等；导入最多产生 Proposal/Candidate/Review Draft。
- 未配置外部 Tunnel 或 ChatGPT Developer Mode 时状态必须为 `BLOCKED_EXTERNAL_ACCOUNT` 或 `DISCONNECTED`，不得回退成公开 localhost。
- `film.chatgpt_app` 及其子 Flag 默认 false；关闭后 Host、Codex、Canvas、Provider 与 Film Core 原路径不变。

## RC 收口边界

- Web 拆包必须先归因，再做路由或重依赖 lazy loading；不提高告警阈值，不用删除功能换指标。记录 before/after 最大 chunk、warning 数量、全量测试、类型检查和构建。
- 统一恢复 runner 必须在临时合成环境中串联 Core、Remote receipt、迁移、Agent/session、Flag rollback 与来源不可变校验；不得扫描或打开用户数据库。
- 上游 Candidate 继续不合并。对 Models/Migrations 的 C 级差异建立合成 schema adapter、可逆 dry-run 与 Golden；原生构建通过不自动把 C 提升为 A/B。
- RC Candidate 只表示本地可验证代码候选，不表示已发布、已签名、已在 ChatGPT 安装或已迁移生产数据。

## 验收主链

`Contracts → ChatGPT Tool v1 → Grant/Auth → Read MCP → Widget → Proposal Export/Import Preview → Recovery → Web bundle → Upstream migration adapter → Golden ChatGPT A/B → Native regression → Flag rollback`

## 暂不自动执行

- 创建 Platform Tunnel、API key、ChatGPT App/Plugin 连接、Developer Mode 操作、Scan Tools 或公开提交。
- 公开 HTTPS endpoint、OAuth 生产 IdP、真实媒体代理上传、ChatGPT 文件上传或对外数据传输。
- 真实 PostgreSQL/用户数据迁移、上游 Candidate 合并、外部生成、额度消费、签名、公证、DMG/PKG 与生产发布。
