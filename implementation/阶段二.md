# 第二阶段｜真实 Golden A

## 目标

将已有默认关闭首切片连成可重放的本地真实链：

`Project → ContentUnit → ScriptVersion → DirectorUnit → Shot/Coverage → ProductionCanvas → PromptDraft → GenerationPackage → ManualImport → Candidate → QC → Human Approval`

## 并行边界

- Core：共享 JSON Schema/OpenAPI、Sidecar 持久化、乐观并发、Review/Approval 人工门。
- Agent：实际 MCP 注册、OpenAPI 同步门、真实 Sidecar Read → Preview → Apply。
- Web/QA：默认关闭的项目/生产画布入口，复用 Prompt/Provider 本地域模块，运行浏览器 Golden、冲突和恢复测试。

## 阶段门

1. 全部 Film Flag 默认关闭时，Host 旧流程 DOM、MCP 工具集与数据不变。
2. 正式写入必须校验 `expected_version` 和内容哈希；冲突时 fail closed。
3. Manual Provider 无网络执行面，本阶段外部 Provider 调用数必须为 0。
4. Candidate 只能经 QC 和显式 Human Approval 进入 Approved，批准绑定当前 content hash。
5. Golden 回执必须区分已准备、已写入、已审查、已批准和外部生成状态。

## 不在本阶段

- Dreamina/Flova/Comfy 真实生成、上传或额度消耗。
- Remote 发布、用户真实数据迁移、Host 核心表不可逆改造。
- SceneTwin/Blocking/Camera/Blender 的 Golden C 完整实现。
