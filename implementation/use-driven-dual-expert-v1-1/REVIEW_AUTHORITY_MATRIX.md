# Review 权限矩阵

| 主体 | 可以 | 不可以 |
| --- | --- | --- |
| 用户 | 报告问题、提出调整、选择产品取舍、授权付费/上传/外部项目/不可逆操作 | 代替系统搬运证据，或被默认为已授权高风险操作 |
| Review Bus | 持久化 IssueSession、冻结 Evidence Manifest、路由 Fast/Core/Architecture | 修改 Film Core 创作真值、自动批准 Candidate |
| Codex | 基于本机源码、日志和可复现环境独立评估与实施 | 代替用户批准付费或不可逆外部动作 |
| ChatGPT | 通过 Secure Tunnel 和只读 MCP 独立复核投影后的 Evidence Pack | 读取本机秘钥、Cookie、原始私密路径，或直接修改工作台 |
| 双专家共识 | 对 Core/Architecture 问题产生可追溯 ConsensusRecord | 绕过用户真正的产品选择和高风险授权 |

权威边界以 `governance/FILMOS_CONSTITUTION.json` 和 Review Bus 机器合同为准；本文是 WP-00 诊断快照，不创建第二权威。
