# Feature Flag Map

| Flag | Scope | Default |
|---|---|---|
| `VITE_FILMOS_AGENT_NATIVE_MULTIBRAIN` | existing Agent profile surface | inherited |
| `VITE_FILMOS_BRAIN_GENERATION_ROUTING` | V2.4 settings/domain | on in candidate builds |
| `VITE_FILMOS_GENERATION_COMPOSER` | existing Canvas composer extension | on in candidate builds |
| `VITE_FILMOS_FLOVA_RUNTIME` | Flova features after F0 | off until verified |
| `FILMOS_REAL_EXTERNAL_GATES` | real-cost acceptance only | off |

Flags may hide entry points; they never change authority, bypass confirmation, substitute providers or enable paid work.
