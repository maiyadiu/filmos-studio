# UI Surface 图

## Review Center

入口：`管理员后台 -> Review Center`

列表：Issue、Scope、Lane、State、Round、三方状态、严重度、Active Candidate、CI、Artifact、更新时间。

详情：现场、Evidence、双盲状态、Consensus、Findings/Responses、Candidate 历史、CI/Artifact、Owner Decision、Dual Signoff、Pilot Gate、Chrome Pairing、Timeline。

## 用户反馈修复

- 反馈 Modal 支持 Command+V 粘贴图片，真实附件字节进入 Evidence Store。
- 章节正文使用同一权威 source text，提供“易读 / Markdown”切换。
- 易读模式渲染 Markdown；Markdown 模式显示原文；不创建第二份正文。
- 长篇剧本导入使用真实章节拆分与可配置上限，不使用错误的短文本限制。
