# Agent 多脑迁移与回滚

## 稳定映射

| 旧数据 | 新数据 | 迁移方式 | 旧数据处理 |
| --- | --- | --- | --- |
| `canvas-agent.json.canvases[*].activeThreadId` | `brain-sessions.v1.json` 中 `codex.subscription.providerThreadId` | 首次启用通用 Runtime 时按 Canvas + Thread 哈希幂等复制 | 保留，不删除，不改写 |
| `online` / `local` Agent 偏好 | `filmos.agent.activeBrainProfileId` | 读取时分别归一为 `openai.api` / `codex.subscription` | 关闭新选择器后仍映射回旧双选项 |
| ChatGPT V1 合并偏好 | 全局 Host Connection + 当前 Project Host Session | 仅在 V2 尚不存在时复制 | V1 UserDefaults 保留一个发布周期供回滚 |

BrainSession 文件只保存会话、Provider Thread、项目/画布范围和迁移标记，不保存 API Key、Cookie、Tunnel Runtime Key 或本机媒体正文。进行中的会话若遇到进程退出，重启后状态归一为 `interrupted`；恢复时根据当前受信 Owner/Project 重新签发短期 Grant，再恢复原 Provider Thread。

## Feature Flags

十个 `film.agent_*` 开关在 integration 默认关闭。`film.agent_generic_runtime` 启用时，Context、Manifest、Broker、no-fallback 和 request-scoped identity 五项安全依赖必须同时启用，否则 Runtime 拒绝启动新路径。Web 与 Canvas Agent 分别使用 `VITE_FILM_AGENT_*` 和 `FILMOS_AGENT_*` 的显式 `true` 值；任何其他值都按关闭处理。

## 回滚

关闭新路径不会删除 `brain-sessions.v1.json`，不会修改旧 Codex Thread、项目、Canvas、资产、Film Core、API Channel、Tunnel ID 或 Keychain Runtime Key。旧 `/agent/codex/*` 路由仍保留。

先做只读预演：

```bash
node canvas-agent/scripts/rollback-native-multibrain.mjs --config /absolute/path/canvas-agent.json
```

确认后执行：

```bash
node canvas-agent/scripts/rollback-native-multibrain.mjs --config /absolute/path/canvas-agent.json --apply
```

脚本只将十个 Agent Flag 写为 `false`，并在同目录保留一次 `canvas-agent.json.pre-native-multibrain-rollback.json`。恢复新路径时可对照备份重新启用 Flag；会话文件和旧 Thread 均仍在。
