## 2. Architecture changes

- Brain Registry: 在影策既有 Agent Runtime 内登记 `codex.subscription`、`chatgpt.subscription.host`、`openai.api`、`anthropic.api`、`deepseek.api`、`local.model`，没有新建平行 Agent 产品。
- Connection modes: Codex 使用 `codex_app_server` 原生流；ChatGPT 使用既有 Tunnel/Host Handoff；API 与本地模型是显式 Profile。
- Session Manager: 单一 `BrainSessionStore` 以 Project/Canvas/Profile/Session 隔离，保留 Provider Thread 并支持重启恢复、撤销与旧 Thread 迁移。
- Context Broker: Workbench Context 由当前浏览器/画布状态生成，显式携带 Project、ContentUnit、Scene、DirectorUnit、Shot、选区、节点、Asset、版本与 Hash；模型提交的身份字段被忽略。
- Visual Context: 继续复用 Canvas 的可见节点、选区、资源与生成任务投影；缺少像素证据时要求脑明确声明证据不足，不伪造视觉事实。
- Tool Broker: 单一 Canonical Manifest/Grant/Confirmation/Policy/Audit 管理 Workbench、Canvas、Project 和 Film 工具；MCP annotations 直接来自同一风险分类。
- Approval/Audit: 高影响、付费、删除与正式 Apply 必须确认；Receipt 一次消费，Film/Canvas 版本和 Hash 必须匹配；审计以 0600 JSONL 持久化且不写 Prompt、Cookie、Key 或 Authorization。
