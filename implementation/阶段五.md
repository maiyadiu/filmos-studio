# 第五阶段｜Beta 硬化

## 目标

在 Golden A/B/C 已通过的本地正式链上完成第 22–28 天 Beta 硬化：

`Remote/Hybrid 本地接线 → 通用 Agent Adapter → 性能基线 → 恢复/迁移包 → 上游候选演练 → 无签名桌面包 → Beta Gate`

## 实施边界

- Remote/Hybrid：接受 `CR-12-001` 的本地接线范围。允许默认关闭的 Preview、Human confirmation、manifest version/hash 守卫、本地同步会话与追加回执；不允许网络执行、隐式上传或把远端结果自动提升为 Approved。
- Agent：Codex、DeepSeek-compatible、Claude-compatible 与 Local Model 共用同一 MCP/Production 工具面；适配器只描述能力和权限，不保存密钥、不直连模型、不绕过 Read → Preview → Human Apply，也不能提交 Approval。
- 迁移：接受 `CR-11-001` 的合成数据/临时副本演练范围。锁定 manifest hash、Stable ID、引用、行数、FK、回执和回滚；不得打开或改写用户真实数据库。没有真实 PostgreSQL 时必须标记 `BLOCKED_REAL_PG`。
- 性能：使用固定合成数据记录环境、数据规模、命令、p50/p95、包体与错误率；先记录基线和预算，再判断，不把单次健康检查当性能证据。
- 上游：重新发现 Stable/Candidate，运行静态差异、原生候选门和回滚 dry-run；任何 D 级失败继续阻断，不为过门禁合并上游。
- 桌面：允许生成可复现的本地 unsigned `.app`、验证 bundle 结构与受控启动边界；代码签名、公证、DMG/PKG 发布和自动更新仍需单独授权与凭据。

## Beta 必验

1. 所有新增能力默认关闭；关闭后 Host 原项目、章节、Canvas、资产、任务与用户数据同步流程不变。
2. Remote/Hybrid 只处理用户明确选择的对象；manifest 漂移、权限、冲突、部分失败和重复执行都失败关闭，网络动作与上传数保持 0。
3. DeepSeek-compatible Adapter 与 Codex 使用相同工具合同；Agent 不能批准、不能扩大工具权限，也不能把密钥写入 URL、日志、配置或业务正文。
4. 合成迁移包可导出、校验、故障恢复和幂等重放；来源不变，回滚后 Stable ID、hash、引用、审计与 receipt 一致。
5. 固定数据集的 Core/Remote/Agent/浏览器关键路径产生可重放性能报告；已知大 chunk 风险必须有精确数据和处置状态。
6. 上游 Candidate 只在全部原生门、迁移和 Golden 通过后才可进入候选；否则保留精确 blocker。
7. unsigned `.app` 可构建、结构可验、最小启动可观测；不得称为已签名安装包或已公证发行版。
8. Beta Gate 汇总 Native、Contract、MCP、Golden、Migration、Recovery、Performance、Browser 与 Rollback；测试通过和业务 Approval/外部发布严格分轴。

## 不在本阶段自动执行

- 读取、迁移、删除或覆盖用户正式项目、数据库、媒体及系统 A/B 原始数据。
- 外部 Provider 生成、远端发布、对象存储上传、额度消费或生产同步。
- Apple Developer 签名、公证、DMG/PKG 发布、自动更新投放或生产开关启用。
- 以 last-write-wins、静默回退、隐式上传或自动 Approval 解决冲突。
